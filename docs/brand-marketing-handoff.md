# Brand and Marketing Handoff

## Naming status

**Confirmed product name:** Snaphub.

**Provisional:** public clearance. Trademark, domain, social handle, store-name, and confusion checks must happen before identity lockup.

## Brand idea

Snaphub should feel like a quiet industrial utility: precise, calm, quick, and trustworthy. The product does not ask for attention; it removes friction and disappears.

The memorable visual behavior is the selected region becoming the workspace, framed by adaptive tools. Brand systems should build from focus, framing, cropping, coordinates, and precise marks rather than generic cloud or camera symbolism.

## Audience and promise

Primary audience: developers, designers, QA, support, educators, and small product teams.

Core promise: **Capture, explain, and continue.**

Supporting messages:

- The useful tools missing from system snipping, exactly where you need them.
- Edit on the screen instead of opening another app.
- Fast while active, nearly invisible while idle.
- Local-first by default; sharing is an explicit later action.

## Differentiators

- Contextual editing around the selected region
- Adaptive, customizable tools without menu depth
- Professional redaction and pinning in the fast path
- Deliberate performance budgets
- Cross-platform architecture with honest platform limitations
- Later Studio and cloud capabilities that do not burden the resident capture core

## Visual direction

- Tone: restrained industrial precision with warm human details.
- Composition: crops, frames, measurement ticks, offset focus rectangles, and purposeful negative space.
- Motion: one decisive capture/focus transition and short state confirmations; avoid ambient motion.
- Typography: distinctive but highly legible grotesk or technical humanist family; avoid default startup typography.
- Product UI typography: Plus Jakarta Sans Variable for interface copy and JetBrains Mono Variable for technical values. Both fonts are bundled locally with the desktop application.
- Capture-writing typography: Caveat Variable provides the approachable handwritten annotation preset and is bundled under the SIL Open Font License; it is not the dashboard/interface font.
- Color: largely neutral interface with one high-visibility focus accent validated over arbitrary desktop imagery.
- Iconography: crisp optical shapes at tray and toolbar sizes; consistent stroke and filled active states.

Avoid purple gradients, glassmorphism everywhere, floating dashboard cards, generic camera-aperture logos, AI sparkles, excessive neon, and claims based on feature count.

## Required brand assets

- Primary, compact, monochrome, tray, and favicon marks
- Light/dark and high-contrast variants
- Capture focus color and semantic interface palette
- Typography licenses and fallback stacks across Windows, macOS, and Linux
- App/store icons at all platform sizes
- Toolbar icon system and active/disabled states
- Installer, update, permission, and empty-state illustrations only where necessary
- Screenshot frame and marketing mockup templates
- Motion principles and short logo/capture transition

## Marketing production list

- Hero still and short loop showing shortcut-to-copy flow
- Window detection, blur/redaction, counter, pin, and scrolling demonstrations
- Comparison visuals centered on flow and cognitive load, not hostile feature tables
- Performance methodology and reference-device disclosure
- Local-first/privacy explanation
- Phase roadmap with clear separation of available and future features

## Landing-page narrative

1. Capture, explain, and continue.
2. Show the full interaction in seconds.
3. Explain the gap between system snipping and heavyweight suites.
4. Demonstrate the five highest-value quick tools.
5. Show lightweight and local-first evidence.
6. Present platform status and honest limitations.
7. Offer the appropriate free or paid action only when packaging is confirmed.
